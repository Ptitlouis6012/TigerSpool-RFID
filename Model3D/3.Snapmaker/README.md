# Snapmaker

Cases that mount a TigerSpool on a Snapmaker printer, one directory per printer
model. The rules every model follows, and the layout inside a model directory,
are in [../README.md](../README.md); a new model starts from
[../TEMPLATE.md](../TEMPLATE.md).

Until one fits your printer, the [desktop stand](../0.Desktop/) works beside any
of them.
